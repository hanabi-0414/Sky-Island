# 空中之島

「空中之島」是以 three.js 製作的單人 3D 方塊遊戲。玩家可以在浮空島上探索、挖掘方塊、收集掉落物，再把方塊放回世界。遊戲以靜態 HTML、CSS 和 JavaScript 執行，不需要帳號、遊戲伺服器或遊戲引擎。

## 開始遊玩

1. 下載或複製此專案。
2. 使用支援 WebGL 的瀏覽器，直接開啟專案根目錄的 `index.html`。
3. 點擊畫面上的開始按鈕進入遊戲。

`index.html` 可直接從本機開啟；three.js 使用專案內的 `vendor/three.min.js`，方塊素材也已隨專案提供。

## 操作方式

| 操作 | 按鍵／方式 |
| --- | --- |
| 移動 | `W`、`A`、`S`、`D` |
| 跳躍 | 空白鍵 |
| 轉動視角 | 移動滑鼠 |
| 挖掘方塊 | 對準方塊並按住滑鼠左鍵 |
| 放置方塊 | 選取有庫存的方塊後，對準方塊並按滑鼠右鍵 |
| 選取物品欄 | 滑鼠滾輪或數字鍵 `1`–`8` |
| 切換日夜 | `N` |
| 重新隨機生成小島 | `R` |

## 遊戲內容

- 小島地形會隨種子隨機變化，世界固定在 `32 × 32 × 32` 格以內。
- 玩家受重力影響，會站在方塊表面；方塊會阻擋玩家，碰牆時仍可沿牆移動。
- 掉出小島後會回到有方塊支撐的安全出生位置。
- 挖掘方塊會產生同種類掉落物；靠近後可拾取，再從物品欄選取並放置。
- 挖除島上所有方塊後，小島會重建，遊戲可以繼續。
- 按 `N` 可在白天和夜晚之間切換；按 `R` 會重新生成地形。

## 開發與檢查

專案使用 Node.js 內建測試工具，不需要安裝 npm 套件。在專案根目錄執行：

```sh
node --test tests/*.test.mjs
```

若修改遊戲模組或素材，可重新產生可直接開啟的單頁 `index.html`：

```sh
node scripts/build-standalone.mjs
```

## 專案結構

- `index.html`：可直接以瀏覽器開啟的獨立遊戲頁面。
- `index.template.html`、`styles.css`：頁面模板與樣式。
- `src/`：遊戲模組，包括地形、物理、挖掘、物品欄、拾取、放置和日夜切換。
- `assets/sky-island-assets/`：作業提供的方塊材質、圖示和挖掘裂痕素材。
- `vendor/three.min.js`：遊戲使用的 three.js。
- `tests/`：遊戲規則與操作的自動化測試。
- `BRIEF.md`、`PLANS.md`、`VERIFY.md`：需求、執行計畫和驗收項目。
